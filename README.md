This is a AP CSA personal project for the AP With WE Project. This code is a website that is suppose to spread awareness to immigration rights and the Connecticut's Trust Act to undocumented and documented immigrants. It is built with HTML, CSS, and Java code in order to get the code live and add some basic design on the website. It also has Spanish and Portuguese translation, so that it can be readable to those that can't read English but can in those languages.
